### 1187. Make Array Strictly Increasing 
<img width="2861" height="1272" alt="image" src="https://github.com/user-attachments/assets/8d579d11-27c5-4967-97ee-9eacc0160479" />


* 解題思路\
  用 dp 紀錄目前所有可能狀態，其中 key 代表目前序列最後一個數字，value 代表達到這個狀態所需要的最少交換次數。初始化為 {-1:0}，表示還沒放任何數字。

  接著依序處理 arr1 的每個數字。對於每個狀態 (prev, cost)，我有兩種選擇。

  第一種是不交換，如果目前數字 num > prev，就可以直接接在後面，交換次數不變。

  第二種是交換，我利用 bisect_right 在排序去重後的 arr2 中找到第一個大於 prev 的數字，把它當成新的尾巴，交換次數加一。

  每次更新時，如果同樣的尾巴數值出現多次，我只保留交換次數較小的那個狀態。

  這題的關鍵是交換時只需要找第一個大於 prev 的數字即可，不需要考慮更大的數字。因為越小的合法數字越容易讓後面的元素接上，所以一定不會比更大的選擇差。

  最後處理完整個 arr1 後，dp 裡面會留下所有合法的遞增序列狀態，取最小交換次數就是答案。如果中途沒有任何合法狀態，就直接回傳 -1。
  
* 程式
```python
from bisect import bisect_right

class Solution(object):
    def makeArrayIncreasing(self, arr1, arr2):
        """
        :type arr1: List[int]
        :type arr2: List[int]
        :rtype: int
        """
        arr2 = sorted(set(arr2))

        dp = {-1: 0}  # {最後一個數: 最少交換次數}

        for num in arr1:
            new_dp = {}

            for prev, cost in dp.items():

                # 不交換
                if num > prev:
                    if num not in new_dp:
                        new_dp[num] = cost
                    else:
                        new_dp[num] = min(new_dp[num], cost)

                # 交換
                idx = bisect_right(arr2, prev)

                if idx < len(arr2):
                    nxt = arr2[idx]

                    if nxt not in new_dp:
                        new_dp[nxt] = cost + 1
                    else:
                        new_dp[nxt] = min(new_dp[nxt], cost + 1)

            dp = new_dp

            if not dp:
                return -1

        return min(dp.values())
