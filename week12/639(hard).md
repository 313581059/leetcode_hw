* 解題思路\
  使用動態規劃來解這題，定義 dp[i] 代表前 i 個字元的解碼方式數量，但因為每次轉移只會用到 dp[i-1] 和 dp[i-2]，所以我用兩個變數 dp0 和 dp1 分別代表 dp[i-2] 和 dp[i-1] 來做空間優化，整體可以壓縮成 O(1) 空間。
  
  初始化的部分，如果第一個字元是 *，它可以代表 1 到 9，所以是 9 種可能，如果是 0 則無法解碼為 0，其餘數字則為 1 種，因此 dp1 初始化為第一個字元的解碼方式數量，dp0 則設為 1，代表空字串的情況。

  接下來從第二個字元開始掃描，每一步都分成兩部分來考慮，第一部分是單獨解碼，也就是當前字元自己形成一個字母，若當前是 * 則有 9 種選擇，因此要乘上 dp[i-1]，如果是一般數字且不是 0 則直接延續 dp[i-1]，第二部分是與前一個字元組合成兩位數來解碼，如果是一般數字組合且落在 10 到 26 之間就可以加上 dp[i-2]，但重點在於 * 的處理。

  如果是 ** 的情況，前一個 * 可以是 1 或 2，當組合成兩位數時，1* 可以形成 11 到 19，共 9 種，而 2* 可以形成 21 到 26，共 6 種，所以總共是 15 種；如果是 *x，則要看 x 的範圍，如果 x 在 0 到 6，前一個 * 可以是 1 或 2，因此有 2 種可能，如果 x 在 7 到 9，則只能由 1x 組成，因此是 1 種；如果是 x *，則當 x 是 1 時可以形成 11 到 19 共 9 種，當 x 是 2 時可以形成 21 到 26 共 6 種，其他情況則無法形成合法兩位數。

  每一步都將單獨解碼與雙字元解碼的結果加總後取模，最後再更新狀態，dp0 會變成原本的 dp1，dp1 則變成目前算出的 cur，這樣等於每次把視窗往右滑動一格，持續維護前兩個狀態即可。

  時間複雜度是 O(n)，因為每個位置只做固定判斷，空間複雜度是 O(1)，因為只使用常數個變數來維護狀態。
* 程式
```python
class Solution(object):
    def numDecodings(self, s):
        """
        :type s: str
        :rtype: int
        """
        MOD = 10**9 + 7
        n = len(s)

        # dp0 = dp[i-2]
        # dp1 = dp[i-1]
        dp0 = 1

        # 第一個字元自己能怎麼解
        if s[0] == '*':
            dp1 = 9
        elif s[0] == '0':
            dp1 = 0
        else:
            dp1 = 1

        for i in range(1, n):
            cur = 0

            # -------- 單獨解碼 --------
            if s[i] == '*':
                cur += 9 * dp1
            elif s[i] != '0':
                cur += dp1

            # -------- 兩位數一起解碼 --------
            prev = s[i - 1]
            curr = s[i]

            # **
            if prev == '*' and curr == '*':
                # 11~19 + 21~26
                cur += 15 * dp0

            # *數字
            elif prev == '*':
                if '0' <= curr <= '6':
                    # 1x 或 2x
                    cur += 2 * dp0
                else:
                    # 只能是1x
                    cur += dp0

            # 數字*
            elif curr == '*':
                if prev == '1':
                    # 11~19
                    cur += 9 * dp0
                elif prev == '2':
                    # 21~26
                    cur += 6 * dp0

            # 普通兩位數
            else:
                if 10 <= int(prev + curr) <= 26:
                    cur += dp0

            cur %= MOD

            dp0 = dp1
            dp1 = cur

        return dp1
